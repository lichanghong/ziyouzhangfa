# 流量

边缘安全加速 ESA通过流量管理功能,在边缘节点对数据流进行监控和调控,有效控制和优化流量分布,防止网络拥塞,不仅可以减轻源站压力,同时也加快了内容的分发速度和用户访问体验。

## 功能介绍

| 功能 | 概述 |
| :--- | :--- |
| 智能路由 | 智能路由服务支持全球节点网络的实时探测和动态路由优化,启用该服务后,将基于阿里云全球边缘节点进行实时网络探测,根据实时网络情况,选择最佳路由传输请求数据,并结合高性能协议栈等优化技术大幅降低全球网络延迟和请求失败率,提升用户体验,保障您业务的连续性。 |
| **等候室** | |
| 快速上手 | 当您的站点因大促或热门活动面临高并发流量冲击时,源站服务器可能因不堪重负而响应缓慢甚至宕机。等候室功能通过在边缘设置虚拟排队区域,对超出源站处理能力的用户请求进行排队,从而保护源站稳定运行,并为排队用户提供明确的等待预期,优化用户体验。 |
| 等候室数据分析 | 等候室分析为您提供了与等候室相关的流量分析工具,使用等候室数据分析,您可以获取等候室和源站的高峰流量、用户在等待室的等待时间等信息,以帮助您调整等候室的设置。 |
| 配置等候室事件 | 如果您需要在特定时间调整等候室的规则,比如改变排队方法或者增减总活动用户数,您可以通过创建等候室计划事件来弹性调整您的等候室配置。 |
| 配置等候室绕过规则 | 如果您希望部分特定的请求即使匹配到等候室规则也可以不进入等候室(例如您想为VIP或内部人员等特殊用户开通绕过等候室的回源直达通道),则可以使用创建等候室绕过规则来确保特定的流量在访问高峰期可以不进入等候室而直接访问源站资源。 |
| 放行搜索引擎爬虫 | 为了避免等候室的排队机制对主流搜索引擎的SEO和搜索结果产生影响,您可以启用放行搜索引擎爬虫功能,使经过Bot Management验证的SEO爬虫程序可以绕过等候室直接访问您的源站资源。 |
| **源地址池** | |
| 源地址池 | 边缘安全加速 ESA通过源地址池功能,在边缘节点对流量进行智能分配和管理,确保流量均匀分布并优化资源利用,提高服务可用性和可靠性,同时提升整体网络性能和用户体验。 |
| **负载均衡** | |
| 负载均衡器管理 | 您可以通过编辑、停用、删除等操作来管理您的负载均衡器。 |
| 负载均衡策略 | 您可以通过主备调度、加权轮询策略、区域调度策略选择符合业务场景策略。 |
| 自定义规则配置 | 如果您的业务有特定用户需求或特定应用场景,您可以使用自定义规则来实现。 |
| 负载均衡全球地区划分 | 本文档提供关于负载均衡策略中区域调度策略的详细地区划分。您可以通过本文档来帮助您配置区域调度策略,将您的请求调度到最近的源地址池,从而提高性能并降低延迟。 |
