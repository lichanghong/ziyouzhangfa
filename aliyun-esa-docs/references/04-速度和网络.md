# 速度和网络

边缘安全加速 ESA在网站性能优化上提供了速度优化和网络优化两种方式。速度优化以图像转换,文件压缩和协议优化为主。网络优化以支持IPv6接入,WebSocket连接,gRPC连接以及文件上传限制来满足不同场景下网站性能的提升。

## 功能介绍

| **优化项** | **详细优化项** | **说明** |
| :--- | :--- | :--- |
| 速度监测 | 网页监测 | 边缘安全加速 ESA网页监测功能通过自动或手动集成JavaScript脚本来实现采集真实用户访问网站的PC端和移动端数据,实时监控核心性能指标,支持HTML页面分析并提供绿/黄/红三色性能分级。 |
| | 自适应性能优化 | ESA速度监测提供了自适应性能优化功能,针对特定错误页面和人机验证页面中动态插入匿名化JS脚本,用于采集用户端性能数据,并将结果传输至数据中心处理和分析。 |
| 速度优化 | 图像转换 | 边缘安全加速 ESA提供图像转换功能,可直接对源站图片进行格式/质量转换、裁剪、缩放等处理并进行缓存,提升获取图片的速度,减少回源流量。 |
| | 资源压缩 | ESA通过文件压缩功能针对静态资源进行压缩,以降低传输的数据量,提升网页加载速度。 |
| | 协议优化 | 当您开启SSL/TLS功能并正确配置了站点证书后,边缘安全加速 ESA默认为您开启HTTP/2和HTTP/3(QUIC)开关,可直接使用HTTP/2和HTTP/3(QUIC)协议。 |
| | Markdown 转换 | AI Agent 或自动化客户端抓取网页时,需要自行解析 HTML 才能提取正文,效率低且容易出错。边缘安全加速 ESA 的 Markdown 转换功能在请求携带 `Accept: text/markdown` 请求头时,可直接以 Markdown 格式返回页面内容,帮助 Agent 获取干净的结构化文本,无需额外的 HTML 解析。 |
| 网络优化 | 网络优化 | 边缘安全加速 ESA提供了网络访问和回源优化、IPv6支持、WebSocket和gRPC连接以及最大上传大小设置等功能。 |
